# MI-BCI-Resources

A collection of publicly available EEG datasets and Machine Learning (ML) toolboxes for
Motor Imagery Brain-Computer Interfaces (MI-BCI), accompanying the review paper:

> **From EEG Signals to Commands: A Review of Machine Learning Pipelines in
> Motor Imagery Brain-Computer Interfaces**
>
> Ardalan Faezmehr, Shahab Fatemi, Vahid Shalchyan, Mohammad Reza Daliri

---

## 📖 About

This repository gathers, in one place, the most commonly used **publicly
available EEG datasets** and **code toolboxes** for building and evaluating
Motor Imagery BCI pipelines. It is intended as a companion resource for readers
of our review paper, as well as for anyone working in the MI-BCI field.

The repository is organized into two main sections:

- 📂 **[`Datasets/`](./Datasets)** — Access links and essential information
  (modality, subjects, classes, original paper) for publicly available
  MI-EEG datasets.
- 🧰 **[`Toolboxes/`](./Toolboxes)** — Common code libraries and toolboxes
  for MI-BCI pipelines, split into:
  - **[`Conventional/`](./Toolboxes/Conventional)** — Classical machine
    learning pipelines (e.g., CSP, FBCSP, LDA, SVM, Riemannian geometry).
  - **[`DeepLearning/`](./Toolboxes/DeepLearning)** — Deep learning
    frameworks and models (e.g., EEGNet, Braindecode, EEG-Conformer).
